# LocalOps 1.0.0

Windows 10/11 (x64) için ilk kararlı sürüm.

- Yinelenen pencere düğmeleri kaldırıldı; Windows'un yerel düğmeleri kullanılıyor.
- İşlem ayrıntıları listeyi kapatmadan sağ panelde açılıyor. İşlem listesi ve ayrıntılar ayrı kaydırılıyor.
- Ayarlar, mevcut sayfa ve filtreler korunarak erişilebilir bir modalda açılıyor.
- GitHub üzerinden açılışta ve dört saatte bir otomatik güncelleme kontrolü, indirme durumu ve kullanıcı tarafından başlatılan kurulum eklendi.
- Disk kökü taraması, döngüsel üst işlem kimlikleri, güncel işlem metrikleri ve sıfır saklama süreli temizlik düzeltildi.
- Electron sandbox'ı etkinleştirildi; IPC kaynak/ana çerçeve doğrulaması ve pencere/gezinme izinleri sıkılaştırıldı.
- Electron ve derleme/test bağımlılıkları güncellendi.

## İndirme

`LocalOps-Setup-1.0.0.exe` dosyasını indirip çalıştırın. `latest.yml` ve `.blockmap` dosyaları uygulamanın güncelleme mekanizması içindir. `SHA256SUMS.txt` dosya bütünlüğünü doğrulamak için sunulur.

Bu sürümün Windows kod imza sertifikası yoktur; Windows yayıncıyı doğrulayamadığını gösterebilir. Güncellemeler sabit GitHub deposundan HTTPS ile alınır ve SHA512 özeti doğrulanır. Authenticode yayıncı doğrulaması için sonraki sürümlerde bir kod imza sertifikası yapılandırılmalıdır.
