# LocalOps 1.0.1

- Geliştirme modunda Chromium'un URL'ye eklediği `/` karakteri nedeniyle ana süreçteki IPC güvenlik kontrolünün geçerli veri isteklerini reddetmesi düzeltildi.
- URL karşılaştırması normalleştiriliyor; farklı kaynak, port, belge veya sorgu parametreleri kabul edilmiyor.
- Geliştirme sunucusuyla gerçek performans grafikleri, ağ bağlantıları, donanım/servis verileri ve sistem sağlığı akışlarını denetleyen regresyon testleri eklendi.
- Üretim arayüz testleri, veri API'lerinin boş dizi döndürmesini başarı saymayacak şekilde güçlendirildi.

Windows x64 için `LocalOps-Setup-1.0.1.exe` dosyasını indirin veya kurulu uygulamada Ayarlar → Güncellemeler bölümünü açın.

Kod imza sertifikası yapılandırılmamıştır; Windows yayıncıyı doğrulayamadığını gösterebilir.
